# Student Score Data Analysis

## Project Overview
This project analyzes student exam performance using Python. The goal is to understand how different factors like gender, parental education, lunch type, and test preparation affect student scores.

## Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
The dataset contains information about students including gender, ethnic group, parental education level, lunch type, and test preparation course.

## Analysis Performed
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Visualization of score distributions
- Relationship between different factors and student performance

## Key Insights
- Students who completed the test preparation course scored higher.
- Parental education level has some impact on student scores.
- Lunch type shows variation in student performance.
